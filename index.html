Warming the depth model…

First visit downloads Depth Anything V2 Small (fp16, about 50 MB) plus the hand model (about 8 MB) and a small pose model. They stay in this browser’s cache. Desktop Chrome or Edge with WebGPU is the intended stage. No account, no API key, no server for the video.

Desktop Chrome or Edge is recommended. A phone can open the page, but the volumetric mirror is built for a laptop GPU.

Palm or point moves the cursor. Pinch confirms. Fist holds the twin. Keys: F, V, H, S.
